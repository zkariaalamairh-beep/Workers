# عمّال - Workers

منصة لربط العملاء بمقدمي الخدمات المهنية وعمال اليومية الأقرب إليهم.

## المميزات

- تسجيل وإنشاء حسابات المستخدمين
- عرض مقدمي الخدمات وعمال اليومية
- البحث والفلترة حسب الخدمة
- إظهار مقدمي الخدمات الأقرب حسب الموقع
- ملفات شخصية وخدمات وأسعار
- تقييمات مرتبطة بالطلبات
- تصميم عربي يدعم RTL
- صفحات الدعم والأسئلة الشائعة
- سياسة الخصوصية والشروط والأحكام

## التقنيات المستخدمة

- ASP.NET Core MVC
- Entity Framework Core
- ASP.NET Core Identity
- SQL Server
- NetTopologySuite
- Bootstrap
- HTML, CSS, JavaScript
